# 동일 이미지 삭제와 유사 이미지 그룹 판정

## v2에서 바뀌는 점

기존 사람 검토 v1에는 삭제용 선택지가 없었다. `near_duplicate`는 시각적 유사도 라벨이며 삭제 승인이 아니었다. v2는 사람이 동일한 최종 이미지라고 판단하는 경우와 서로 다른 결과를 그룹으로 남기는 경우를 분리한다.

| 사람 선택 | 의미 | 후속 처리 의도 |
|---|---|---|
| 동일 — 중복 삭제 | 같은 최종 이미지. 포맷·압축·해상도 차이는 허용하지만 서로 다른 생성 결과는 제외 | 표시된 대표 1개 유지, 나머지 중복의 논리삭제 계획 |
| 거의 동일 — 그룹핑 | 작은 차이가 있어도 서로 별도 결과로 보존할 가치가 있음 | 둘 다 보존, 그룹 관계 |
| 같은 시각적 계열 | 구도·스타일·대상 등이 관련되어 함께 참고할 가치가 있음 | 둘 다 보존, 그룹 관계 |
| 주제만 동일 / 무관 | 시각적 중복 또는 같은 시각 계열이라고 볼 근거가 부족함 | 개별 보존 |
| 판단 보류 | 확정할 수 없음 | 조치 보류; 검증된 정답에서 제외 |

`identical`은 사람의 시각 판단이다. SHA-256 또는 픽셀의 완전 일치를 새로 관측했다는 뜻이 아니며, 모델 점수나 프롬프트 일치만으로 이 라벨을 만들지 않는다. 기존 기계 중복 규칙인 `exact_file OR (exact_pixels AND prompt_exact)`와 별도의 사람이 명시한 처리 근거다.

## 삭제의 경계

화면에서 선택하는 것은 처리 의도를 기록하는 일이다. 선택 즉시 파일이나 데이터베이스를 삭제하지 않는다. JSON을 전달하고 입력 검증을 통과한 뒤, 직접 검토한 쌍의 대표·제외 대상이 명시된 계획을 만든다.

이번 수정은 검토 UI와 검증된 삭제/그룹 **계획**까지다. 실제 운영 목록·검색에 적용하는 단계는 별도다. 여기서 계획하는 삭제는 복구 가능한 논리삭제이며 원본 파일, 프롬프트, 출처와 이력을 보관한다. R2·Qdrant·정본의 물리삭제나 공개 배포는 수행하지 않는다.

대표는 기존 JSON 구조화 우선순위를 사용한다. 왼쪽에 있다는 이유로 대표가 되지 않는다. 삭제 대상과 유지 대상을 화면에서 확인한 뒤 동일 판정을 내린다. 이미 기계 중복으로 제외된 대조군은 새 삭제 건으로 세지 않는다.

현재 80쌍 가운데 6쌍에는 이미 제외된 항목이 포함되어 있다. 양쪽 모두 제외되었거나 다른 대표로 연결된 항목도 있다. 이 카드는 일반 목록의 활성 항목이 아니라 판정 기준을 확인하는 대조군이다. 어떤 라벨을 선택해도 새 삭제·복구 대상으로 삼지 않으며, `동일` 판정 역시 비교용 정답으로만 기록한다.

직접 승인하지 않은 쌍을 추론해서 삭제하지 않는다. A-B와 B-C가 동일로 판정되어도 A-C를 검토한 것으로 취급하지 않는다. 다른 판정과의 충돌, 대표까지 삭제되는 연결 또는 모호한 중복 처리 대상은 추가 확인이 필요한 차단 상태로 남긴다.

## 기존 검토의 보존

- v1 HTML·spec·JSON·브라우저 초안은 덮어쓰지 않는다.
- 새 화면은 `human-similarity-review-v2.html`이다.
- v1 판정을 가져오더라도 `near_duplicate`는 그룹 의도로만 옮기며 삭제로 승격하지 않는다.
- 삭제하려면 v2에서 해당 쌍을 직접 `동일 — 중복 삭제`로 선택해야 한다.
- 기존 80쌍과 이미지·벡터·manifest 결합을 유지한다. 이번 UI 변경을 위해 임베딩을 다시 호출하지 않는다.

## 사람의 다음 행동

1. v2 화면을 열고 실제 검토자 이름을 입력한다.
2. 이미지를 비교한다. 필요한 경우 원본 프롬프트와 모델 점수를 펼쳐 본다.
3. 동일 이미지라면 대표/제외 대상을 확인하고 `동일 — 중복 삭제`를 선택한다. 차이가 있는 결과는 그룹핑으로 남긴다.
4. JSON을 내려받아 전달한다. 인입 도구는 기본 dry-run이고, `--apply`도 private 판정·처리 계획 기록에 한정한다.
5. 실제 삭제/그룹 적용 여부와 대상을 확인한다. 검토하지 않은 이미지까지 자동으로 확장하지 않는다.

Luna 메타데이터 작업은 여전히 준비 전용이며 이 사람 판정을 대신하지 않는다.
